# Google Pay Review Analysis

## Project Overview
An end-to-end data analytics project focused on analyzing Google Pay customer reviews to understand customer feedback, ratings and sentiment patterns.

## Project Objectives
- Analyze customer ratings and reviews.
- Identify positive and negative customer feedback.
- Explore review trends and patterns.
- Perform data cleaning and exploratory data analysis.
- Generate insights from customer feedback.

## Tools & Technologies
- Python
- SQL
- MySQL
- Pandas
- Data Visualization
- NLP / Sentiment Analysis (where implemented)

## Project Workflow
1. Dataset Understanding
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. SQL Query Analysis
5. Sentiment Analysis
6. Visualization and Insights

## Repository Structure
- `data/` – Sample dataset
- `notebooks/` – Python analysis
- `sql/` – SQL queries
- `images/` – Project screenshots
- `reports/` – Project findings
